# Formulas

In order to write marketing materials, I have documented many formats that can work for particualr things.
Not all will apply but these formats / hooks can be referenced when needed.

## Landing Pages

### Online Assessment 

[The $1 Million Landing Page](https://www.youtube.com/watch?v=az1Zh-FNSno&t=197s)

**Landing Page**

Hero section 
- Frustration / results hook
- Sub heading leads people to take an assesment

Value Proposition
- We're going to measure and improve these 3 things

Credibility Section
- Who is this?
- What have you done in the past?
- What Research have you done / got? ( to validate the assesment )

Call to action
- Takes 3 mins
- Completely Free / no obligation
- Immediate feedback / improvements

**Questionnaire**

- Name
- Email
