# Momentum

## 1. What am I offering?

A monthly website care service that not only updates and maintains but monitors and improves the effectivness of the website each month based on the below 4 pillars.

1. Health ( Is everything working properly? ) — WordPress/core/plugin updates, security, backups, broken functionality, errors, compatibility, general technical health.
2. Performance ( Is everything fast and technically efficient? ) — Core Web Vitals, page speed, image optimisation, caching, unnecessary scripts/assets, database/site performance.
3. Visibility ( Can the right people and AI systems discover the business? ) — technical SEO, Search Console monitoring, indexing/crawl issues, schema, metadata, internal linking, page structure, keyword opportunities, local SEO/on-page improvements.
4. Conversion ( Does that attention turn into meaningful business? ) — calls to action, enquiry journeys, forms, UX problems, landing/service pages, mobile usability, analytics observations and iterative improvements.

Above all of this is Strategy.

Every month you're effectively asking:
"What's the most valuable thing we can improve about this website next?"

## 3. What problem is Momentum actually solving?

Momentum keeps your website effective as the digital landscape changes.

**Why would my ideal customer pay me every month rather than simply hiring a developer/SEO person when they need one?**

Because most businesses don't know when their website needs attention, what needs improving, or which improvement is most valuable.

An ad-hoc developer is usually reactive: the client identifies a problem or asks for a change, and the developer implements it. An SEO consultant may focus primarily on search visibility. Traditional website maintenance keeps WordPress updated and fixes problems, but doesn't necessarily make the website more effective.

Momentum is proactive.

Rather than waiting for the client to identify work, I continuously monitor the website across four areas — Health, Performance, Visibility and Conversion — identify opportunities and problems, prioritise what will have the greatest impact, and make improvements every month.

This means the website isn't simply maintained in its current state. It gets better over time.

The client is ultimately paying for someone to take ongoing ownership of the effectiveness of their website, without needing to employ an internal web developer or digital team.

So why monthly?

Websites operate in an environment that is continuously changing. Search behaviour changes. Competitors change. Google changes. WordPress/plugins change. Content becomes outdated. Business priorities change. New data accumulates. Users reveal how they're actually interacting with the site.

So there's always a new question: What should we improve next?

## 4. What exactly happens every month?

**Monitor → Diagnose → Prioritise → Improve → Measure → Repeat**

1. Monitor

The website is continuously/regularly monitored across the four Momentum pillars.
( The important thing is that a lot of monitoring should eventually be automated. )

Health
- uptime
- WordPress/plugin/theme updates
- security issues
- backups
- PHP/compatibility/errors
- broken functionality/links where appropriate
Performance
- Core Web Vitals
- page speed
- performance regressions
- page weight/assets
- caching/image issues
Visibility
- Search Console
- indexing/crawl issues
- organic clicks/impressions
- rankings/query opportunities
- pages gaining/losing visibility
- technical/on-page SEO issues
Conversion
- analytics
- enquiry/form performance
- important user journeys
- mobile UX
- landing/service page effectiveness
- obvious conversion opportunities

2. Diagnose

Once per month, you review what the monitoring/data is telling you.

You're looking for things such as:

"This important service page has dropped in search."
"This page is suddenly getting significantly more impressions."
"Mobile Core Web Vitals have deteriorated."
"This service gets traffic but doesn't have a good enquiry route."
"Google is indexing URLs that shouldn't exist."
"The homepage CTA is weak."
"These three pages are competing for similar searches."
"Nothing urgent is wrong, but this service page could be significantly stronger."

This is where your judgement starts becoming the product.

3. Prioritise

You decide: "What is the highest-value thing we can realistically improve this month?"

Potentially rank issues/opportunities internally by something like:
Impact × confidence × effort.

That stops you spending three hours shaving 80ms off a page when there's a service page sitting at position #6 for an extremely valuable search query. It also makes Momentum feel strategic rather than like maintenance.

4. Improve

Then you actually do the work.

**Keep it healthy. Make it better.**
First: keep the website within defined standards across the four pillars.
Then: continually invest effort into the highest-value opportunity for improvement.

You spend around 2 - 5 hours a month on the website as defined above ( keep healthy, then improve ).
This time might be wrong so track the first few customers really hard to know what the average time is.

5. Measure

This is the bit I'd really want in Momentum. Changes get logged. Then subsequent months ask: "Did it work?"

Not every change will produce a measurable result immediately, particularly SEO.
But over time you're building a history:

January: Improved service-page structure.
February: Impressions +22%; average position 11 → 8.
March: "Improved title/meta based on query data.
April: CTR 1.8% → 3.1%.
etc.

Now the client can see that their website isn't simply receiving "maintenance."
It's evolving.

6. Report

I would keep this extremely simple.

Momentum — October
Website health: All good ✓
What I found: Your commercial-property page is receiving increasing Google impressions but ranking near the bottom of page one.
What I improved: Restructured the page, improved headings/content targeting, strengthened internal links and updated metadata.
Why: Moving this page higher could expose it to significantly more relevant searches.
What I'm watching: Search impressions, position and clicks over the coming months.
Next: Review mobile enquiry journey.
