# Website Momentum Monthly Playbook

## Purpose

This playbook defines the standard monthly workflow for every Website Momentum client.

The goal is to ensure every website remains secure, healthy and continually improving over time.

---

# Phase 1 — Essential Maintenance

Complete these recurring maintenance tasks every month.

## Security

- [ ] Update WordPress core
- [ ] Update plugins
- [ ] Update themes
- [ ] Verify backups are completing successfully
- [ ] Review security logs
- [ ] Run a malware scan
- [ ] Check SSL certificate
- [ ] Verify uptime monitoring

## Technical Health

- [ ] Fix broken links
- [ ] Resolve PHP warnings or errors
- [ ] Review failed scheduled tasks (cron)
- [ ] Optimise the database
- [ ] Review disk usage
- [ ] Remove unused plugins and themes
- [ ] Test all contact forms
- [ ] Check email deliverability (where applicable)

---

# Phase 2 — Review

Review the website to identify new opportunities.

## Analytics

- [ ] Review Google Analytics
- [ ] Review Google Search Console
- [ ] Review Core Web Vitals
- [ ] Check crawl errors
- [ ] Review keyword rankings
- [ ] Review recent enquiries or conversions
- [ ] Review heatmaps/session recordings (if available)

## Business

- [ ] Check for client requests
- [ ] Review recent business updates
- [ ] Identify seasonal opportunities
- [ ] Review competitor activity (optional)

## Backlog

- [ ] Review existing Momentum backlog
- [ ] Add any newly identified opportunities

---

# Phase 3 — Prioritise

Score potential improvements using:

- Business impact
- Ease of implementation
- Time available within the client's plan
- Urgency
- Seasonal relevance

Choose the highest-value improvements for this month's implementation.

---

# Phase 4 — Implementation

Complete the selected improvements.

## Performance

Examples:

- Improve Core Web Vitals
- Optimise images
- Improve caching
- Optimise database
- Accessibility improvements

## Visibility

Examples:

- Improve page SEO
- Create landing pages
- Internal linking
- Add schema markup
- Improve Google Business Profile

## Conversion

Examples:

- Improve calls to action
- Simplify forms
- Improve page layouts
- Add testimonials
- Improve copy
- Reduce friction

## Content

Examples:

- Publish blog articles
- Create case studies
- Update service pages
- Refresh existing content
- Add FAQs

## Automation & Growth

Examples:

- CRM integrations
- AI features
- Email automations
- Workflow improvements
- New functionality
- Launch campaigns
- Create new landing pages

---

# Phase 5 — QA

Before marking the month's work as complete:

- [ ] Test affected pages
- [ ] Test all forms
- [ ] Test mobile experience
- [ ] Check page speed (where relevant)
- [ ] Verify automations
- [ ] Check for visual issues
- [ ] Confirm backups are healthy

---

# Phase 6 — Report & Plan

Record what was completed.

## Monthly Report

- [ ] Summarise work completed
- [ ] Record measurable results
- [ ] Note any issues encountered
- [ ] Recommend next steps

## Momentum Backlog

- [ ] Remove completed items
- [ ] Re-prioritise remaining items
- [ ] Add newly identified opportunities

The Momentum backlog should always represent the next highest-value improvements for the website.
