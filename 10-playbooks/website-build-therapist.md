# Enigma Website Build Playbook

## Purpose

This playbook defines the standard workflow for building therapist websites using the Enigma theme.

While every project is unique, most follow a similar structure. This process ensures every website is built consistently, efficiently and to a high standard.

---

# Phase 1 — Discovery

## Gather Information

- [ ] Send client questionnaire
- [ ] Confirm business name
- [ ] Confirm domain
- [ ] Confirm contact details
- [ ] Confirm services
- [ ] Confirm preferred colour palette
- [ ] Request logo
- [ ] Request brand assets
- [ ] Request photography
- [ ] Request testimonials
- [ ] Request social media links
- [ ] Request booking system details
- [ ] Request legal policies (Privacy, Cookies, Terms)

## Define Website Structure

Create a sitemap.

Typical pages:

- [ ] Home
- [ ] About

- [ ] FAQs
- [ ] Contact

Optional:

- [ ] Blog
- [ ] Resources
- [ ] Workshops
- [ ] Courses
- [ ] Testimonials
- [ ] Pricing

# Definition of Done

A website is only considered complete when:

- All agreed pages have been built.
- All forms are working.
- The site performs well on desktop and mobile.
- Basic SEO has been completed.
- Analytics is configured.
- The client has approved the website.
- The website has been launched successfully.
